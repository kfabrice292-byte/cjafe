2. Audit : Forces (Existant)

Présence Sociale

Une page Facebook active avec un grand nombre de publications documentant la vie du centre.

Communauté

Existence d'une base d'abonnés constituant un noyau dur pour les futures campagnes.

Authenticité

Utilisation de photographies réelles des formations (Ateliers, Camps) renforçant la crédibilité.

Accessibilité

Contacts et informations pratiques (numéros, localisation) facilement trouvables.

2. Audit : Axes d'Amélioration

Visibilité Faible

Le ratio Abonnés / Volume de publications est trop faible. L'audience croît trop lentement.

Charte Graphique

Manque d'uniformité dans les couleurs et polices utilisées sur les visuels, diluant la marque.

Contenu Informatif

La communication relate les faits, mais valorise trop peu "l'impact" (témoignages, réussites).

Écosystème Web

Aucune plateforme web centralisée pour structurer l'offre (Pôles, Inscriptions en ligne).

7. Perspectives d'Avenir

Acquisition Payante

Prévoir un budget publicitaire (Facebook Ads) pour sponsoriser les lancements de cohortes.

Preuve Sociale

Filmer les "Success Stories" des anciens apprenants pour rassurer les futurs inscrits.

Trafic Web

Insérer systématiquement le lien du site web dans chaque publication Facebook et TikTok.

E-learning

Finaliser la production des cours en ligne payants pour monétiser la rubrique du site web.

Conclusion

Grâce à la nouvelle identité visuelle, la restructuration stratégique et le lancement du site web officiel, le CJ-AFE dispose aujourd'hui d'outils modernes pour asseoir sa crédibilité.
